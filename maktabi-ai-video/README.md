# مكتبي AI — فيديو الشرح بالثيم الجديد

شرح فكرة **مكتبي AI** (المساعد الذكي للأعمال الحكومية) بنفس محتوى ونفس صوت الفيديو الأصلي،
مُعاد تصميمه بالكامل داخل الثيم المرفق (الأخضر/الأزرق بالزخارف الإسلامية) بعد تطويره بعناصر تقنية الذكاء الاصطناعي.

## المخرجات (`output/`)

| الملف | الوصف |
|---|---|
| `maktabi-ai.mp4` | الفيديو النهائي 1920×1080، ‏30 إطارًا/ث، بالصوت والترجمة المكتوبة |
| `maktabi-ai-subtitles.srt` | ملف الترجمة (الكلام المكتوب) منفصلًا |
| `theme-ai.jpg` | الثيم بعد التطوير (بدون محتوى) لاستخدامه في أعمال أخرى |

## ما الذي تغيّر عن الفيديو الأصلي

- **الثيم**: صورة الخلفية المرفقة + طبقة ذكاء اصطناعي: مسارات دوائر إلكترونية ذهبية/فيروزية تنطلق من الأقواس،
  شبكات عصبية متوهجة في الزوايا، شبكة سداسية خفيفة، حلقات دوّارة حول النجمتين المعلّقتين، موجات بيانات متحركة
  أسفل الشاشة، وجزيئات ضوئية — مع رمز «مكتبي AI» (نجمة ثمانية إسلامية بقلب ذكي).
- **الصوت**: نفس التعليق الصوتي والموسيقى الأصلية، مع إضافة التسجيلين المرسلين:
  - `assets/voice-intro.m4a` في المقدمة («في ظل الثورة الرقمية للذكاء الاصطناعي… لوزارة الأوقاف والشؤون الدينية»)
    — كانت المقدمة في الأصل موسيقى فقط.
  - `assets/voice-2m12.m4a` عند الدقيقة **2:12** تقريبًا («ويمكن للمساعد تنبيه الموظف عبر جرس إشعارات…
    مع إبرازها على سطح المكتب لمتابعتها أولًا بأول») — كان الصوت مفقودًا في الأصل في هذا الموضع رغم وجود
    الكلام المكتوب. تمت مطابقة نبرة التسجيل ومستوى صوته مع التعليق الأصلي، ومُدّت الموسيقى بدل تسريع الصوت،
    مع الإبقاء على نغمة الإشعار متزامنة مع جرس التنبيه في المشهد.
- **الكلام المكتوب**: ترجمة متزامنة أسفل الشاشة لكل جملة.
- **الخاتمة**: «إعداد العمل — فريق عمل الدكتور أحمد بن علي الشعيبي».

## إعادة البناء

```bash
python3 build_audio.py      # build/soundtrack.wav + build/timeline.json
python3 build_subs.py       # build/subs.json + output/maktabi-ai-subtitles.srt
node render.js --workers 3  # output/maktabi-ai.mp4  (Playwright + ffmpeg)
node render.js --still 19,40,150   # لقطات اختبار في build/stills/
```

`scene.html` / `scene.css` / `scene.js` تحتوي التصميم والحركة (GSAP، زمن حتمي لكل إطار).
الخطوط: Readex Pro و IBM Plex Sans Arabic (رخصة OFL).
